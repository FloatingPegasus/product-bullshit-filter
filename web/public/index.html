Product Bullshit Filter

Listing in, measurable facts out

Extension

Paste a marketplace URL. The site fetches the page and runs the same rules as the extension: specs against slogans, seller and warranty, and the reviews that are actually in the HTML.

When a store blocks this site

Amazon and Flipkart often refuse a server. The Chrome extension reads the tab you already have open, including the text a bot never receives. Load the extension folder from this repo with Developer mode on.
